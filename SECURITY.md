# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability. Send an email to
**security@sakuga.dev** with:

- the affected version,
- the steps to reproduce,
- the impact that you expect.

We answer within 5 working days, and we keep you informed until the fix ships. We credit you
in the release notes, unless you ask us not to.

## Supported versions

Only the latest minor version gets security fixes while Genga is in 0.x.

## Scope

The security model of Genga is in [docs/security.md](./docs/security.md).
